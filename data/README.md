# Fine-tuning data

`train.jsonl` and `validation.jsonl` are generated by
`scripts/prepare-training-data.py`. They contain 540 training and 60
validation examples: a balanced mix of reviewed English Q&A and grade-school
multi-step math problems with worked solutions.

## Sources and licenses

- [OpenAssistant/oasst1](https://huggingface.co/datasets/OpenAssistant/oasst1),
  Apache-2.0. English assistant replies are paired with their parent prompts;
  the preparation script filters for reviewed, top-ranked, higher-quality
  responses and excludes flagged or high-toxicity examples.
- [openai/gsm8k](https://huggingface.co/datasets/openai/gsm8k), MIT. The
  training split supplies math questions and worked solutions; the original
  test split is not used.

The preparation script pins each dataset revision and verifies the downloaded
Parquet file checksums. Raw downloads are kept under `data/raw/` and excluded
from Git; regenerate the curated JSONL files with:

```sh
uv run python scripts/prepare-training-data.py
```

The examples teach concise visible explanations and final answers. They are
not a guarantee of reliable or general-purpose deep reasoning. Review the
source dataset licenses and content before redistributing the derived files.
